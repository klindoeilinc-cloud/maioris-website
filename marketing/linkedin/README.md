# Kit de diffusion LinkedIn

Ce dossier n'est pas publié sur le site. Il contient :

- `kit-fr.md` et `kit-en.md` : 20 publications chacune, à relire, adapter à votre voix, puis publier vous-même.
- `calendrier-10-semaines.md` : l'ordre de publication proposé.

## Voix

Les textes sont écrits avec « nous », la voix de MAIORIS. Pour publier depuis le profil du fondateur, vous pouvez passer au « je » : relisez alors les phrases sur les cas, qui doivent rester exactes.

## Règles à ne jamais enfreindre

1. **Un scénario fictif est toujours signalé comme tel dans le texte du post lui-même**, jamais seulement dans le lien. Les publications concernées contiennent déjà la mention.
2. **Le Case 01** est un retour d'expérience du fondateur, antérieur à MAIORIS. Ne l'attribuez jamais à MAIORIS. La mention figure dans la publication C1.
3. Aucun client, résultat ou témoignage ne doit être ajouté sans accord et sans source.
4. Aucune promesse de résultat. Le calculateur est une estimation fondée sur les données du visiteur.
5. Répondez aux commentaires dans les 24 heures : c'est ce qui transforme une publication en conversation.

## Liens suivis

Chaque lien porte `utm_source=linkedin`, `utm_medium=social` et un `utm_campaign` par publication. Dans Plausible, ouvrez Sources puis UTM pour voir quelle publication amène quelles visites, et créez les objectifs `contact_submit` et `cta_click` pour voir lesquelles mènent à un contact.

## Visuels

Chaque analyse a une image de partage prête dans `site/assets/og/` (aperçu automatique du lien sur LinkedIn). Pour une publication sans lien dans le texte, téléchargez l'image correspondante.
